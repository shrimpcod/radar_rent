# CIAN Parser

Простой парсер объявлений с Циан.

## Установка

```bash
cd cian_parser
pip install -r requirements.txt
```

## Запуск

```bash
python parser.py
```

## Структура проекта

```
cian_parser/
├── __init__.py      # Пакет Python
├── config.py         # Конфигурация (URL, заголовки)
├── parser.py         # Основной парсер
├── requirements.txt  # Зависимости
└── README.md         # Этот файл
```

## Что делает парсер

1. Делает HTTP запрос к API Циан
2. Получает JSON с данными о квартирах
3. Парсит данные согласно маппингу из `explanation/cian-parser-attributes.md`
4. Выводит JSON со всей информацией о каждом объявлении
